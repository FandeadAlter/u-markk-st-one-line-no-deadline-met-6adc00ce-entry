Entry for [u-markk-st-one-line-no-deadline-met-6adc00ce](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce) ($2). Run with `MAKEFUN_OUTPUT_DIR=out node main.ts` (Node 22, standard library only). The program is deterministic: two runs write identical bytes.
